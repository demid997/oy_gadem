# ENGLISH LESSONS ADMIN — стартовая версия

Отдельный административный сайт преподавателя. Ученический кабинет будет отдельным репозиторием.

## Что уже работает
- Премиальный тёмный интерфейс с фиолетово-синими акцентами и адаптацией под телефон.
- Демо-режим с сохранением данных в браузере.
- Обзор, расписание по дням, добавление/редактирование/удаление занятий.
- Ученики, журнал, фильтр дат и статистика.
- Защита от простого совпадения времени занятий в интерфейсе.

## Запуск локально
ES-модули и Firebase CDN требуют запуск через локальный веб-сервер, а не `file://`.
Например, в папке проекта:
```bash
python -m http.server 8000
```
Откройте `http://localhost:8000`.

Демо-режим включён: `USE_DEMO_MODE = true` в `firebase.js`.

## Подключение Firebase
1. Используем переданный Firebase project `fintech-app-88d34`; CRM хранит свои записи отдельно в узле `/englishLessons/`.
2. В Firebase Console проекта `fintech-app-88d34` добавьте Web App и перенесите полный Web App config в `firebase.js` (apiKey, authDomain, projectId, appId, messagingSenderId и точный storageBucket).
3. Включите Email/Password в Authentication.
4. Создайте Realtime Database.
5. Настройте серверное назначение custom claim `role: "admin"` доверенному аккаунту.
6. Установите `USE_DEMO_MODE = false`.
7. Разверните строгие Realtime Database Rules и Cloud Functions до включения реальных пользовательских данных.

**Важно:** текущая сборка — интерфейсный стартовый каркас. В демо-режиме логин не проверяется. Не размещайте реальные данные учеников до настройки Firebase Auth, custom claims и правил доступа.

## Безопасность и следующие этапы
- Нельзя доверять проверке роли только в браузере: роль администратора проверяется через Firebase custom claims и правила базы.
- SMTP-пароль, service-account JSON и приватные ключи нельзя помещать в этот репозиторий или браузерный код.
- Отправку писем нужно выполнять только через защищённую Cloud Function с секретом в Secret Manager.
- Создание ученических аккаунтов и одноразовая выдача паролей — через Admin SDK в Cloud Functions, не из клиентского JavaScript.
- Перед продакшеном добавить транзакционную проверку пересечения интервалов занятий (включая длительность), журнал аудита, резервное копирование, rate limiting и тесты правил.

## GitHub Pages
Для простого старта можно опубликовать репозиторий через Settings → Pages → Deploy from a branch → main → /(root).
Для Firebase Authentication добавьте домен GitHub Pages в Authorized domains.

## Используемая база
Переданный Realtime Database URL прописан в `firebase.js`. CRM использует отдельную ветку `/englishLessons/` и не должна читать/перезаписывать корень базы или данные других приложений. Сам URL не является полной конфигурацией Firebase Web App: остальные поля берутся в Project settings → Your apps. См. официальную документацию Firebase.
